# Приложение для работы с БД "Военкомат"

Приложение для управления базой данных "Военкомат" на Qt5.5.1 (MinGW, C++11).

## Требования

- Qt 5.5.1 или выше
- MinGW компилятор с поддержкой C++11
- PostgreSQL сервер (версия 17.6)
- Драйвер QPSQL для Qt

## Установка и сборка

1. Убедитесь, что PostgreSQL установлен и запущен
2. Восстановите базу данных из бэкапа `sql_zaproses/new_backup.sql`:
   ```bash
   psql -U postgres -d voenkomat -f sql_zaproses/new_backup.sql
   ```
   Или используйте PowerShell:
   ```powershell
   $env:PGPASSWORD = "ваш_пароль"
   & "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h localhost -p 5432 -U postgres -d voenkomat -f sql_zaproses\new_backup.sql
   ```

3. Настройте переменную окружения для пароля:
   ```powershell
   $env:PGPASSWORD = "ваш_пароль"
   ```
   Или установите постоянно (см. `docs/password_setup.md`)

4. Откройте проект в Qt Creator:
   - Файл -> Открыть файл или проект
   - Выберите `voenkomat_app.pro`

5. Соберите проект (Ctrl+B)

## Структура проекта

```
voenkomat_app/
├── src/                    # Исходный код
│   ├── main.cpp           # Точка входа
│   ├── DatabaseManager.*  # Управление подключением к БД
│   ├── MainWindow.*       # Главное меню
│   ├── TablesWindow.*     # Управление таблицами
│   ├── QueriesWindow.*    # Работа с запросами
│   ├── QueryResultWindow.* # Отображение результатов запросов
│   ├── TableViewWindow.*  # Просмотр данных таблиц
│   ├── BackupManager.*    # Резервное копирование
│   ├── ConfigManager.*    # Управление конфигурацией
│   └── ...
├── resources/
│   └── queries/           # SQL-запросы из ЛР5 и ЛР6 (2.1.1.sql - 2.1.34.sql)
├── docs/                   # Документация
│   ├── assignment.md      # Задание ЛР7-8
│   ├── LR5_Report.md      # Отчет лабораторной работы №5
│   ├── LR6_Report.md      # Отчет лабораторной работы №6
│   ├── database_schema.md # Описание схемы БД
│   └── ...
├── sql_zaproses/          # Бэкапы БД и старые запросы
│   ├── new_backup.sql     # Актуальный бэкап БД
│   └── LR6_Queries/       # Дубликаты запросов (можно удалить)
├── exports/               # Папка для экспорта данных (SQL и CSV)
├── config.ini             # Конфигурация подключения (НЕ в Git!)
├── config.ini.example     # Шаблон конфигурации
└── voenkomat_app.pro      # Файл проекта Qt
```

## Функциональность

- **Управление таблицами**: добавление, удаление, редактирование структуры
- **Работа с данными**: просмотр, добавление, редактирование, удаление записей
- **Резервное копирование**: экспорт таблиц и всей БД в SQL с сохранением всех constraints, индексов и sequences. Восстановление из бэкапа
- **Работа с запросами**: выполнение сохранённых запросов из ЛР5 и ЛР6, добавление новых запросов
- **Экспорт данных**: 
  - Экспорт результатов запросов в CSV
  - Экспорт таблиц в CSV
  - Экспорт в SQL файлы

## Использование

1. Установите переменную окружения `PGPASSWORD` с паролем от БД (см. `docs/password_setup.md`)
2. Запустите приложение
3. При первом запуске приложение автоматически создаст `config.ini` с настройками подключения
4. Используйте меню для навигации:
   - **Запросы** - выполнение SQL-запросов из ЛР5 и ЛР6, добавление новых запросов
   - **Таблицы** - просмотр и управление таблицами
   - **Добавить таблицу** - создание новой таблицы
   - **Экспорт данных** - создание резервной копии всей БД
   - **Восстановить данные** - восстановление всей БД из бэкапа
   - **Восстановить таблицу** - восстановление отдельной таблицы из бэкапа

5. В окнах просмотра данных доступны:
   - **Экспорт в CSV** - экспорт результатов запросов и таблиц в CSV формат

## Конфигурация

Параметры подключения к БД хранятся в файле `config.ini`:
- Хост, порт, база данных, пользователь - в `config.ini`
- Пароль - в переменной окружения `PGPASSWORD` (безопаснее, чем хранить в файле)

Подробнее см. `docs/password_setup.md` и `docs/database_connection.md`

## Примечания

- **ВАЖНО**: Проект использует C++11 (требование Qt 5.5.1 MinGW) - не обновлять стандарт!
- SQL-запросы загружаются из папки `resources/queries/` (34 запроса из ЛР5 и ЛР6)
- Экспортированные данные сохраняются в папку `exports/`
- Файл `config.ini` добавлен в `.gitignore` для защиты пароля
- Документация находится в папке `docs/`
