# Инструкция по управлению системой "Военкомат"

Система спроектирована по стандарту CUA (Common User Access) и ориентирована на управление с клавиатуры.

## Навигация
- **Tab**: Переход между элементами управления (кнопки, поля ввода).
- **Shift + Tab**: Переход в обратном направлении.
- **Стрелки (↑ ↓ ← →)**: Навигация внутри списков и текстовых полей.
- **Enter**: Подтверждение действия (кнопка "ОК").
- **Esc**: Отмена или закрытие текущего окна.

## Работа с Меню
- **F10**: Активировать главное меню.
- **Alt + [Подчеркнутая буква]**: Быстрый доступ к разделу меню (например, Alt+F для File).

## Горячие клавиши (Shortcuts)
- **Ctrl + V**: Просмотр данных.
- **Ctrl + A**: Добавить запись.
- **Ctrl + U**: Изменить (Update) запись.
- **Ctrl + D**: Удалить (Delete) запись.
- **Ctrl + Q**: Специальные запросы.
- **Ctrl + S**: Сохранить результат в файл.
- **Ctrl + B**: Создать бэкап БД.
- **Ctrl + E**: Выход.

## Помощь
- **F1**: Вызов этой справки в приложении.
