ПАПКА С ОТДЕЛЬНЫМИ SQL ЗАПРОСАМИ ДЛЯ LR6
==========================================

⚠️ ВНИМАНИЕ: Эта папка содержит ДУБЛИКАТЫ запросов из папки resources/queries/
Файлы идентичны, но оставлены для удобства ручного запуска через pgAdmin или скрипты.

Эта папка содержит 34 отдельных SQL файла - по одному запросу в каждом файле.

СТРУКТУРА:
- 2.1.1.sql - 2.1.34.sql - файлы с запросами
- Каждый файл содержит один запрос с комментарием

ИСПОЛЬЗОВАНИЕ:

1. В pgAdmin:
   - Откройте любой файл (например, 2.1.1.sql)
   - Нажмите F5 для выполнения
   - Просмотрите результаты

2. Через скрипт автоматизации:
   - Запустите LR6_Queries_Runner.bat (для Windows)
   - Или LR6_Queries_Runner.ps1 (для PowerShell)
   - Скрипт выполнит все запросы последовательно с паузами

НАСТРОЙКА СКРИПТА:
Перед запуском скрипта отредактируйте параметры подключения к БД:
- DB_HOST (обычно localhost)
- DB_PORT (обычно 5432)
- DB_NAME (имя вашей базы данных)
- DB_USER (обычно postgres)
- PGPASSWORD (пароль - установите переменную окружения)
