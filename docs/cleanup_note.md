# Примечание об удалении дубликатов запросов

## Дубликаты запросов

В проекте обнаружены дубликаты SQL запросов:
- `resources/queries/` - актуальные запросы (используются приложением)
- `sql_zaproses/LR6_Queries/` - дубликаты (34 файла)

## Проверка

Проверено несколько запросов - файлы идентичны. Запросы в `resources/queries/` соответствуют отчетам ЛР5 и ЛР6.

## Рекомендация

Папку `sql_zaproses/LR6_Queries/` можно удалить, так как:
1. Все запросы уже есть в `resources/queries/`
2. Приложение использует только `resources/queries/`
3. Дубликаты создают путаницу

**Однако**, перед удалением рекомендуется:
- Убедиться, что все запросы в `resources/queries/` работают корректно
- Создать резервную копию на случай необходимости восстановления

## Команда для удаления (после проверки)

```powershell
Remove-Item -Path "sql_zaproses\LR6_Queries" -Recurse -Force
```

Или вручную через Проводник Windows.
