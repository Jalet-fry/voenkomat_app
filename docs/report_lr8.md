# ВВЕДЕНИЕ

Современные информационные системы невозможно представить без эффективной работы с базами данных. Разработка прикладных программ, способных не только управлять данными, но и выполнять сложные транзакции, резервное копирование и экспорт информации, становится важнейшей задачей для обеспечения стабильности и удобства работы пользователей.

Целью данной работы является создание прикладного программного обеспечения для взаимодействия с базой данных «Военкомат», реализующего весь необходимый функционал для эффективного управления данными. Программа должна обеспечивать просмотр таблиц с возможностью фильтрации по каждому полю, редактирование структуры данных (включая добавление, изменение и удаление записей), а также поддерживать создание резервных копий для последующего восстановления как отдельных таблиц, так и всей базы данных целиком.

Отдельное внимание уделяется реализации работы с запросами: пользователь должен иметь возможность видеть результаты уже существующих запросов из лабораторных работ №5 и №6, использовать их без необходимости ручного написания SQL-кода, а также сохранять результаты для дальнейшей работы. Кроме того, необходимо реализовать возможность добавления новых запросов и их сохранения. Важным элементом является экспорт таблиц и результатов запросов в файлы удобного для пользователя формата, например Excel, что делает работу с данными более гибкой и удобной.

Для реализации проекта был выбран язык программирования C++11 и фреймворк Qt 5.5.1 (32-bit), что позволяет создать кроссплатформенное приложение с современным графическим интерфейсом. В качестве системы управления базами данных используется PostgreSQL, а для работы с файлами Excel применяется библиотека QXlsx.

В отчёте будут представлены полное руководство пользователя, описание интерфейса приложения, а также листинг программного кода, обеспечивающего реализацию всех вышеуказанных функций.

# ИСХОДНЫЕ ДАННЫЕ

## 1.1 Условие и порядок выполнения

Создание прикладной программы для работы с базой данных и выполняющей заданные транзакции, а также реализовать механизм работы с базой данных: 

– работа с записями в таблицах (просмотр, редактирование, удаление, добавление записей);

– разработать механизм экспорта каждой таблицы, результатов запросов в файл (например формата .xlsx для просмотра в Excel).

Остальная функциональность определяется преподавателем, выдающим лабораторную работу.

Можно использовать любую среду и язык программирования. Писать запрос в приложении нельзя для 5 и 6 лабораторной работы! (нужно реализовать интерфейс вывода запросов из 5 и 6 лабораторной работы). Добавление новых запросов приветствуется, сохранение уже реализованных запросов – обязательно! В отчете отразить руководство пользователя и листинг кода.

## 1.2 Описание приложения

Приложение предназначено для работы с базой данных «Военкомат». Приложение выполняет следующие функции: добавление записи, удаление записи, просмотр таблиц (с возможностью фильтрации по каждому полю, реализуемое так же через запросы), удаление записи, выполнение заданных SQL запросов из 5 и 6 лабораторных работ, экспорт данных всех таблиц базы данных, а также экспорт результатов запросов в файл формата .xlsx. Для разработки приложения был выбран язык программирования C++, для создания графического интерфейса – фреймворк Qt 5.5.1 (32-bit). Данные технологии были выбраны по следующему ряду причин:

– язык C++ является компилируемым и кроссплатформенным языком программирования, что, таким образом, означает, что скомпилированное в исполняемый файл приложение может быть запущено на большинстве современных платформ без дополнительных манипуляций;

– фреймворк Qt предоставляет мощные средства для создания графических интерфейсов с высоким уровнем абстракции, что упрощает разработку и обеспечивает единообразный внешний вид приложения;

– наличие встроенной поддержки работы с базами данных через модуль Qt SQL, который обеспечивает удобный доступ к различным СУБД, включая PostgreSQL;

– наличие библиотеки QXlsx для работы с файлами Excel, что позволяет реализовать экспорт данных в удобном для пользователя формате.

Минимальные требования к ОС для запуска приложения:

1) Windows:

– Windows 7 и выше либо Windows Server 2008 R2 и выше;

– Наличие установленного и запущенного сервера PostgreSQL;

– Наличие драйвера QPSQL для Qt (обычно поставляется вместе с Qt).

2) Linux:

– Для Qt 5.5.1: версия ядра 2.6.32 и выше;

– Наличие установленного и запущенного сервера PostgreSQL;

– Наличие драйвера QPSQL для Qt.

3) macOS:

– macOS 10.9 (Mavericks) или более поздней версии;

– Наличие установленного и запущенного сервера PostgreSQL;

– Наличие драйвера QPSQL для Qt.

Используемые библиотеки и компоненты:

– Qt: версия 5.5.1 (32-bit);

– Qt SQL: модуль для работы с базами данных;

– QXlsx: библиотека для работы с файлами Excel;

– PostgreSQL: система управления базами данных;

– C++11: стандарт языка программирования.

Работа приложения показана в среде Windows. При запуске приложения открывается главное меню, содержащее 6 кнопок, позволяющие определить режим работы приложения: «Запросы», «Таблицы», «Экспорт данных», «Восстановить данные», «Восстановить таблицу» и «Выйти». При нажатии соответствующей кнопки появляются новые функциональности в рамках выбранного режима работы, которые будут рассмотрены подробнее в дальнейшем. **Рисунок 3.1 – Просмотр таблицы «Призывники»**

Для того, чтобы отфильтровать результат основного запроса, который возвращает все записи из таблицы, используется панель фильтров, расположенная над таблицей. Панель фильтров содержит поля для каждого столбца таблицы, тип которых автоматически определяется системой на основе типа данных столбца в базе данных:

- Для текстовых полей (VARCHAR, TEXT, CHAR) – поле ввода текста с поиском по подстроке (LIKE);
- Для целочисленных полей (INTEGER, BIGINT, SMALLINT) – поле ввода с валидатором для целых чисел;
- Для числовых полей с плавающей точкой (NUMERIC, DECIMAL, FLOAT, REAL, DOUBLE) – поле ввода с валидатором для чисел с плавающей точкой;
- Для полей даты (DATE) – виджет выбора даты с календарем;
- Для полей даты и времени (TIMESTAMP, TIME) – виджет выбора даты и времени;
- Для логических полей (BOOLEAN, BOOL) – выпадающий список с опциями "Да", "Нет" и пустым значением.

После ввода значения в поле фильтра система автоматически применяет фильтр с задержкой 500 миллисекунд после последнего изменения (debounce механизм), что предотвращает излишние запросы к базе данных при быстром вводе. Для сброса всех фильтров используется кнопка «Сбросить фильтры». Операция фильтрации призывников по полю «ФИО» показана на рисунке 3.2.

#include "MainWindow.h"
#include <QApplication>
#include <QCoreApplication>
#include <QDir>
#include <QFileInfo>
#include <QDebug>

int main(int argc, char *argv[])
{
    // Устанавливаем путь к плагинам Qt ДО создания QApplication
    // Это критически важно для загрузки SQL драйверов
    
    QStringList pluginPaths;
    
    // 1. Стандартный путь Qt (для разработки)
    QString qtPluginsPath = "C:/Qt/Qt5.5.1/5.5/mingw492_32/plugins";
    if (QDir(qtPluginsPath).exists()) {
        pluginPaths << qtPluginsPath;
    }
    
    // 2. Путь относительно исполняемого файла (для релизных сборок)
    QString exePath = QString::fromLocal8Bit(argv[0]);
    QFileInfo exeInfo(exePath);
    QDir exeDir = exeInfo.absoluteDir();
    
    // Проверяем plugins рядом с exe
    QString localPlugins = exeDir.absoluteFilePath("plugins");
    if (QDir(localPlugins).exists()) {
        pluginPaths << localPlugins;
    }
    
    // 3. На уровень выше от debug/release
    if (exeDir.cdUp()) {
        QString parentPlugins = exeDir.absoluteFilePath("plugins");
        if (QDir(parentPlugins).exists()) {
            pluginPaths << parentPlugins;
        }
    }
    
    // Устанавливаем переменную окружения QT_PLUGIN_PATH
    if (!pluginPaths.isEmpty()) {
        QString pluginPathEnv = pluginPaths.join(";");
        qputenv("QT_PLUGIN_PATH", pluginPathEnv.toLocal8Bit());
        qDebug() << "Установлена переменная QT_PLUGIN_PATH:" << pluginPathEnv;
    }
    
    // Также добавляем пути через QCoreApplication (до создания QApplication)
    foreach (const QString &path, pluginPaths) {
        QCoreApplication::addLibraryPath(path);
    }
    
    QApplication app(argc, argv);
    
    MainWindow window;
    window.show();
    
    return app.exec();
}

bool createTable(const QString &tableName, const QList<QPair<QString, QString>> &columns, 
                 const QStringList &primaryKeys = QStringList());
bool dropTable(const QString &tableName, bool cascade = false);
bool addColumn(const QString &tableName, const QString &columnName, const QString &dataType, 
              bool isNullable = true, const QVariant &defaultValue = QVariant());
bool dropColumn(const QString &tableName, const QString &columnName);
bool alterColumnType(const QString &tableName, const QString &columnName, const QString &newDataType);

// Реализация в DatabaseManager.cpp:

bool DatabaseManager::createTable(const QString &tableName, const QList<QPair<QString, QString>> &columns, 
                                  const QStringList &primaryKeys)
{
    if (tableName.isEmpty() || columns.isEmpty()) {
        m_lastError = "Название таблицы и список колонок не могут быть пустыми";
        return false;
    }
    
    QStringList existingTables = getTableList();
    if (existingTables.contains(tableName, Qt::CaseInsensitive)) {
        m_lastError = QString("Таблица %1 уже существует").arg(tableName);
        return false;
    }
    
    QStringList columnDefs;
    foreach (const auto &col, columns) {
        QString colDef = QString("%1 %2").arg(escapeIdentifier(col.first)).arg(col.second);
        columnDefs << colDef;
    }
    
    QString sql = QString("CREATE TABLE %1 (\n    %2\n)").arg(escapeIdentifier(tableName))
        .arg(columnDefs.join(",\n    "));
    
    if (!primaryKeys.isEmpty()) {
        QStringList pkColumns;
        foreach (const QString &pk, primaryKeys) {
            pkColumns << escapeIdentifier(pk);
        }
        sql += QString(",\n    PRIMARY KEY (%1)").arg(pkColumns.join(", "));
    }
    
    bool ok;
    executeQuery(sql, &ok);
    return ok;
}

bool DatabaseManager::dropTable(const QString &tableName, bool cascade)
{
    if (tableName.isEmpty()) {
        m_lastError = "Название таблицы не может быть пустым";
        return false;
    }
    
    QString sql = QString("DROP TABLE %1").arg(escapeIdentifier(tableName));
    if (cascade) {
        sql += " CASCADE";
    }
    
    bool ok;
    executeQuery(sql, &ok);
    return ok;
}

bool DatabaseManager::addColumn(const QString &tableName, const QString &columnName, const QString &dataType, 
                                bool isNullable, const QVariant &defaultValue)
{
    if (tableName.isEmpty() || columnName.isEmpty() || dataType.isEmpty()) {
        m_lastError = "Название таблицы, колонки и тип данных не могут быть пустыми";
        return false;
    }
    
    QStringList existingColumns = getColumnList(tableName);
    if (existingColumns.contains(columnName, Qt::CaseInsensitive)) {
        m_lastError = QString("Колонка %1 уже существует в таблице %2").arg(columnName).arg(tableName);
        return false;
    }
    
    QString sql = QString("ALTER TABLE %1 ADD COLUMN %2 %3")
        .arg(escapeIdentifier(tableName))
        .arg(escapeIdentifier(columnName))
        .arg(dataType);
    
    if (!isNullable) {
        sql += " NOT NULL";
    }
    
    if (defaultValue.isValid() && !defaultValue.isNull()) {
        QString defValue = defaultValue.toString();
        if (!defValue.contains(QRegExp("^[0-9]+$")) && 
            !defValue.contains(QRegExp("^[A-Z_]+\\("))) {
            defValue = QString("'%1'").arg(defValue.replace("'", "''"));
        }
        sql += QString(" DEFAULT %1").arg(defValue);
    }
    
    bool ok;
    executeQuery(sql, &ok);
    return ok;
}

bool DatabaseManager::dropColumn(const QString &tableName, const QString &columnName)
{
    if (tableName.isEmpty() || columnName.isEmpty()) {
        m_lastError = "Название таблицы и колонки не могут быть пустыми";
        return false;
    }
    
    QStringList existingColumns = getColumnList(tableName);
    if (!existingColumns.contains(columnName, Qt::CaseInsensitive)) {
        m_lastError = QString("Колонка %1 не существует в таблице %2").arg(columnName).arg(tableName);
        return false;
    }
    
    QString sql = QString("ALTER TABLE %1 DROP COLUMN %2")
        .arg(escapeIdentifier(tableName))
        .arg(escapeIdentifier(columnName));
    
    bool ok;
    executeQuery(sql, &ok);
    return ok;
}

// Добавлены следующие методы в TablesWindow:

void TablesWindow::createTable()
{
    if (!m_dbManager || !m_dbManager->isConnected()) {
        QMessageBox::warning(this, "Ошибка", "База данных не подключена");
        return;
    }
    
    CreateTableDialog dialog(this);
    if (dialog.exec() == QDialog::Accepted) {
        QString tableName = dialog.getTableName();
        QList<QPair<QString, QString>> columns = dialog.getColumns();
        QStringList primaryKeys = dialog.getPrimaryKeys();
        
        if (m_dbManager->createTable(tableName, columns, primaryKeys)) {
            QMessageBox::information(this, "Успех", QString("Таблица '%1' успешно создана").arg(tableName));
            refreshTables();
        } else {
            QMessageBox::critical(this, "Ошибка", 
                QString("Не удалось создать таблицу:\n%1").arg(m_dbManager->lastError()));
        }
    }
}

void TablesWindow::deleteTable(const QString &tableName)
{
    if (!m_dbManager || !m_dbManager->isConnected()) {
        QMessageBox::warning(this, "Ошибка", "База данных не подключена");
        return;
    }
    
    int ret = QMessageBox::question(this, "Подтверждение удаления",
        QString("Вы уверены, что хотите удалить таблицу '%1'?\n\n"
                "Это действие необратимо и приведет к потере всех данных в таблице!")
        .arg(tableName),
        QMessageBox::Yes | QMessageBox::No, QMessageBox::No);
    
    if (ret == QMessageBox::Yes) {
        int cascadeRet = QMessageBox::question(this, "Каскадное удаление",
            "Удалить также все зависимые объекты (внешние ключи, индексы и т.д.)?",
            QMessageBox::Yes | QMessageBox::No, QMessageBox::No);
        
        bool cascade = (cascadeRet == QMessageBox::Yes);
        
        if (m_dbManager->dropTable(tableName, cascade)) {
            QMessageBox::information(this, "Успех", QString("Таблица '%1' успешно удалена").arg(tableName));
            refreshTables();
        } else {
            QMessageBox::critical(this, "Ошибка", 
                QString("Не удалось удалить таблицу:\n%1").arg(m_dbManager->lastError()));
        }
    }
}

    if (!m_dbManager || !m_dbManager->isConnected()) {

        return;
    }
    
    EditTableStructureDialog dialog(m_dbManager, tableName, this);
    if (dialog.exec() == QDialog::Accepted) {
        refreshTables();
    }
