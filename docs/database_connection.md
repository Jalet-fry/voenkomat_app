# Инструкция по получению параметров подключения к БД

## Найденные параметры из файлов проекта

Из анализа кода и файлов проекта найдены следующие параметры:

- **Хост (Host):** `localhost`
- **Порт (Port):** `5432`
- **База данных (Database):** `voenkomat`
- **Пользователь (Username):** `postgres`
- **Пароль (Password):** *требуется указать*

## Способы получения параметров подключения

### Способ 1: Через pgAdmin

1. Откройте **pgAdmin**
2. В левой панели найдите сервер PostgreSQL
3. Правой кнопкой мыши на сервере → **Properties** (Свойства)
4. Вкладка **Connection** (Подключение):
   - **Host name/address:** обычно `localhost` или `127.0.0.1`
   - **Port:** обычно `5432`
   - **Maintenance database:** обычно `postgres`
   - **Username:** обычно `postgres`
   - **Password:** ваш пароль (если сохранен, будет скрыт)

5. Для проверки имени базы данных:
   - Разверните сервер → **Databases**
   - Найдите базу данных `voenkomat` (или другую, если используется другая)

### Способ 2: Через консоль (psql)

#### Windows PowerShell:

```powershell
# Подключиться к PostgreSQL
psql -U postgres

# Или с указанием хоста и порта
psql -h localhost -p 5432 -U postgres

# После подключения выполнить:
\l                    # Список всех баз данных
\c voenkomat          # Подключиться к базе voenkomat
\conninfo             # Показать информацию о текущем подключении
```

#### Windows CMD:

```cmd
psql -U postgres
```

### Способ 3: Проверка через SQL запрос

После подключения к базе данных выполните:

```sql
-- Показать текущие параметры подключения
SELECT 
    current_database() as database_name,
    current_user as username,
    inet_server_addr() as server_host,
    inet_server_port() as server_port,
    version() as postgresql_version;
```

### Способ 4: Проверка файла конфигурации PostgreSQL

Файл конфигурации обычно находится в:
- Windows: `C:\Program Files\PostgreSQL\[версия]\data\postgresql.conf`
- Порт можно найти в строке: `port = 5432`

## Проверка подключения

### Тест через psql:

```powershell
# Установить переменную окружения для пароля (временно)
$env:PGPASSWORD = "ваш_пароль"

# Проверить подключение
psql -h localhost -p 5432 -U postgres -d voenkomat -c "SELECT version();"
```

### Тест через приложение:

После создания конфигурационного файла `config.ini`, приложение автоматически подключится к БД при запуске.

## Создание конфигурационного файла

После получения всех параметров, создайте файл `config.ini` в корне проекта:

```ini
[Database]
host=localhost
port=5432
database=voenkomat
username=postgres
password=ваш_пароль_здесь
```

**ВНИМАНИЕ:** Файл `config.ini` будет добавлен в `.gitignore`, чтобы не попасть в систему контроля версий.

## Альтернатива: Использование переменной окружения

Можно использовать переменную окружения `PGPASSWORD`:

**Windows PowerShell:**
```powershell
$env:PGPASSWORD = "ваш_пароль"
```

**Windows CMD:**
```cmd
set PGPASSWORD=ваш_пароль
```

**Постоянная установка (Windows):**
1. Правой кнопкой на "Этот компьютер" → Свойства
2. Дополнительные параметры системы → Переменные среды
3. Добавить новую переменную:
   - Имя: `PGPASSWORD`
   - Значение: ваш пароль

## Рекомендации

1. **Безопасность:** Не храните пароль в открытом виде в коде
2. **Конфигурационный файл:** Используйте `config.ini` с правами доступа только для владельца
3. **Переменная окружения:** Более безопасный способ, чем хранение в файле
4. **.pgpass файл:** Можно создать файл `%APPDATA%\postgresql\pgpass.conf` для автоматической аутентификации
