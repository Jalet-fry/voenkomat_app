# Задание для лабораторной работы №7-8

## Создание приложения для базы данных

Создание прикладной программы для работы с базой данных и выполняющей заданные транзакции, а также реализовать механизм работы с базой данных:

- **Добавление новой таблицы** - возможность создавать новые таблицы в базе данных
- **Удаление существующих таблиц** - возможность удалять таблицы из базы данных
- **Работа с таблицами** - редактирование, удаление, добавление полей в существующих таблицах
- **Создание резервной копии** - для восстановления удаленной таблицы, строк, всей базы данных
- **Вывод созданных новых запросов** - возможность их сохранения для последующего использования
- **Экспорт данных** - разработать механизм экспорта каждой таблицы, результатов запросов в файл (например Excel)

Можно использовать любую среду и язык программирования.

## Важные требования

**Писать запрос в приложении нельзя для 5 и 6 лабораторной работы!**

- Нужно реализовать интерфейс вывода запросов из 5 и 6 лабораторной работы
- Добавление новых запросов приветствуется
- Сохранение уже реализованных запросов - обязательно!

## Требования к отчету

В отчете отразить:
- Руководство пользователя
- Листинг кода
