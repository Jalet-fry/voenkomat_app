# Задание для лабораторной работы №7-8

## Создание приложения для базы данных

### План выполнения работы

Создание прикладной программы для работы с базой данных и выполняющей заданные транзакции, а также реализовать механизм работы с базой данных:

– работа с записями в таблицах (просмотр, редактирование, удаление, добавление записей);

– разработать механизм экспорта каждой таблицы, результатов запросов в файл (например формата .xlsx для просмотра в Excel).

Остальная функциональность определяется преподавателем, выдающим лабораторную работу.

Можно использовать любую среду и язык программирования. **Писать запрос в приложении нельзя для 5 и 6 лабораторной работы!** (нужно реализовать интерфейс вывода запросов из 5 и 6 лабораторной работы). Добавление новых запросов приветствуется, сохранение уже реализованных запросов – обязательно! В отчете отразить руководство пользователя и листинг кода.

### Описание приложения

Приложение предназначено для работы с базой данных «Военкомат». Приложение выполняет следующие функции: добавление записи, удаление записи, просмотр таблиц (с возможностью фильтрации по каждому полю, реализуемое так же через запросы), обновление записи, выполнение заданных SQL запросов из 5 и 6 лабораторных работ, экспорт данных всех таблиц базы данных, а также экспорт результатов запросов в файл формата .xlsx.

### Важные требования

**Писать запрос в приложении нельзя для 5 и 6 лабораторной работы!**

- Нужно реализовать интерфейс вывода запросов из 5 и 6 лабораторной работы
- Добавление новых запросов приветствуется
- Сохранение уже реализованных запросов - обязательно!

### Требования к отчету

В отчете отразить:

- Руководство пользователя
- Листинг кода

### Функциональность приложения

1. **Просмотр таблиц** - просмотр всех записей в таблице с возможностью фильтрации по каждому полю
2. **Добавление записи** - добавление новой записи в таблицу через форму
3. **Удаление записи** - удаление записи из таблицы по ID
4. **Обновление записи** - редактирование существующей записи в таблице
5. **Выполнение SQL-запросов** - выполнение сохраненных запросов из ЛР5 и ЛР6
6. **Экспорт результатов запросов** - сохранение результатов запросов в файл формата .xlsx (формат: query_YYYY-MM-DD_HH-MM-SS.xlsx)
7. **Сохранение состояния БД** - экспорт всех таблиц базы данных в файл формата .xlsx, где каждая таблица на отдельном листе (формат: backup_YYYY-MM-DD_HH-MM-SS.xlsx)

### Примечание

**Важно:** В данном приложении работа ведется только с данными (записями) в существующих таблицах. Создание и удаление самих таблиц не требуется - только работа со значениями (добавление, редактирование, удаление записей).
