# Настройка пароля через переменную окружения

## Безопасный способ хранения пароля

Пароль **НЕ хранится** в файле `config.ini` для безопасности. Вместо этого используется системная переменная окружения `PGPASSWORD`.

## Установка переменной окружения

### Способ 1: Временная установка (для текущей сессии PowerShell)

```powershell
$env:PGPASSWORD = "12345"
```

**Примечание:** Эта переменная будет действовать только в текущем окне PowerShell. После закрытия окна она исчезнет.

### Способ 2: Постоянная установка (для всех сессий)

#### Windows PowerShell (для текущего пользователя):

1. Откройте PowerShell от имени администратора
2. Выполните:
   ```powershell
   [System.Environment]::SetEnvironmentVariable("PGPASSWORD", "12345", "User")
   ```
3. Перезапустите PowerShell

#### Через графический интерфейс Windows:

1. Нажмите **Win + X** → **Система**
2. Нажмите **Дополнительные параметры системы**
3. Нажмите **Переменные среды**
4. В разделе **Переменные пользователя** нажмите **Создать**
5. Введите:
   - **Имя переменной:** `PGPASSWORD`
   - **Значение переменной:** `12345`
6. Нажмите **ОК** везде
7. **Перезапустите** все приложения, которые используют эту переменную

### Способ 3: Через командную строку (CMD)

```cmd
setx PGPASSWORD "12345"
```

**Примечание:** После выполнения `setx` нужно перезапустить командную строку/PowerShell.

## Проверка установки

Выполните в PowerShell:

```powershell
$env:PGPASSWORD
```

Должно вывести: `12345`

Или:

```powershell
Get-Item Env:PGPASSWORD
```

## Как работает приложение

1. При запуске приложение читает параметры из `config.ini`:
   - Хост, порт, база данных, пользователь
2. Пароль берется из переменной окружения `PGPASSWORD`
3. Если переменная не установлена, приложение попытается использовать пустой пароль (что приведет к ошибке подключения)

## Рекомендации

- ✅ Используйте переменную окружения для пароля
- ✅ Не храните пароль в файлах конфигурации
- ✅ Не добавляйте `config.ini` с паролем в систему контроля версий
- ✅ Используйте `config.ini.example` как шаблон без пароля

## Устранение проблем

### Проблема: "password authentication failed"

**Причина:** Переменная `PGPASSWORD` не установлена или содержит неправильный пароль.

**Решение:**
1. Проверьте переменную: `$env:PGPASSWORD`
2. Установите правильный пароль: `$env:PGPASSWORD = "ваш_пароль"`
3. Перезапустите приложение

### Проблема: Переменная не сохраняется после перезагрузки

**Причина:** Использован временный способ установки (`$env:PGPASSWORD`).

**Решение:** Используйте постоянную установку через `setx` или графический интерфейс Windows.
