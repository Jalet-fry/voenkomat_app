# Руководство пользователя приложения "Военкомат"

## Введение

Приложение "Военкомат" предназначено для управления базой данных PostgreSQL, содержащей информацию о призывниках, комиссарах, военных билетах, медицинских освидетельствованиях и других связанных данных.

## Требования

- Windows 10 или выше
- PostgreSQL 17.6
- Qt 5.5.1 (включено в установку приложения)
- Переменная окружения `PGPASSWORD` с паролем от базы данных

## Установка и настройка

### 1. Настройка переменной окружения

Перед запуском приложения необходимо установить переменную окружения `PGPASSWORD`:

**Windows PowerShell:**
```powershell
$env:PGPASSWORD = "ваш_пароль"
```

**Постоянная установка:**
1. Нажмите Win + X → Система
2. Дополнительные параметры системы → Переменные среды
3. Создайте новую переменную:
   - Имя: `PGPASSWORD`
   - Значение: ваш пароль от PostgreSQL

### 2. Восстановление базы данных

Если база данных еще не создана, восстановите её из бэкапа:

```powershell
$env:PGPASSWORD = "ваш_пароль"
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h localhost -p 5432 -U postgres -d voenkomat -f sql_zaproses\new_backup.sql
```

### 3. Запуск приложения

1. Откройте Qt Creator
2. Откройте проект `voenkomat_app.pro`
3. Соберите проект (Ctrl+B)
4. Запустите приложение (Ctrl+R)

При первом запуске приложение автоматически создаст файл `config.ini` с настройками подключения.

## Основные функции

### Главное меню

При запуске приложения открывается главное меню с следующими опциями:

- **Запросы** - выполнение SQL-запросов из лабораторных работ №5 и №6
- **Таблицы** - просмотр и управление таблицами базы данных
- **Добавить таблицу** - создание новой таблицы
- **Экспорт данных** - создание резервной копии всей базы данных
- **Восстановить данные** - восстановление всей базы данных из бэкапа
- **Восстановить таблицу** - восстановление отдельной таблицы из бэкапа

### Работа с запросами

1. Нажмите кнопку **"Запросы"** в главном меню
2. Выберите запрос из списка (кнопки с номерами 1-34)
3. Результаты запроса отобразятся в новом окне
4. В окне результатов доступны:
   - Просмотр данных в таблице
   - Экспорт результатов в CSV файл
   - Кнопка "Назад" для возврата к списку запросов

**Добавление нового запроса:**
1. Нажмите кнопку **"Добавить"** в окне запросов
2. Введите название запроса
3. Введите SQL-запрос
4. Нажмите "OK" - запрос будет сохранен и выполнен

**Удаление запроса:**
1. Правой кнопкой мыши на кнопке запроса
2. Выберите "Удалить запрос"
3. Подтвердите удаление

### Работа с таблицами

1. Нажмите кнопку **"Таблицы"** в главном меню
2. Выберите таблицу из списка
3. В окне просмотра таблицы доступны:
   - Просмотр всех записей
   - Добавление новой записи (кнопка "Добавить")
   - Редактирование записи (правой кнопкой мыши → "Изменить")
   - Удаление записи (правой кнопкой мыши → "Удалить")
   - Экспорт таблицы в CSV (кнопка "Экспорт в CSV")

**Добавление записи:**
1. Нажмите кнопку **"Добавить"**
2. Заполните поля формы
3. Нажмите "Сохранить"

**Редактирование записи:**
1. Выберите строку в таблице
2. Правой кнопкой мыши → "Изменить"
3. Измените нужные поля
4. Нажмите "Сохранить"

**Удаление записи:**
1. Выберите строку в таблице
2. Правой кнопкой мыши → "Удалить"
3. Подтвердите удаление

### Создание новой таблицы

1. Нажмите кнопку **"Добавить таблицу"** в главном меню
2. Введите название таблицы
3. Добавьте колонки:
   - Название колонки
   - Тип данных (integer, varchar, text, date, timestamp и т.д.)
   - Размер (для varchar)
   - NOT NULL (обязательное поле)
4. Нажмите "Создать"

### Редактирование структуры таблицы

1. Откройте таблицу через меню "Таблицы"
2. В окне просмотра таблицы доступны опции редактирования структуры (если реализовано)

### Резервное копирование

**Экспорт всей базы данных:**
1. Нажмите **"Экспорт данных"** в главном меню
2. Файл будет сохранен в папке `exports/` с именем `full_export_YYYYMMDD-HHMMSS.sql`

**Экспорт отдельной таблицы:**
1. Откройте таблицу
2. Используйте функцию экспорта (если доступна)

**Восстановление из бэкапа:**
1. Нажмите **"Восстановить данные"** или **"Восстановить таблицу"**
2. Выберите файл бэкапа (.sql)
3. Подтвердите восстановление
4. ⚠️ **Внимание:** Все текущие данные будут удалены!

### Экспорт данных

**Экспорт результатов запроса в CSV:**
1. Выполните запрос
2. В окне результатов нажмите **"Экспорт в CSV"**
3. Выберите место сохранения файла
4. Файл будет сохранен в формате CSV с кодировкой UTF-8

**Экспорт таблицы в CSV:**
1. Откройте таблицу
2. Нажмите **"Экспорт в CSV"**
3. Выберите место сохранения файла

CSV файлы можно открыть в Microsoft Excel или других табличных редакторах.

## Валидация данных

При добавлении или редактировании записей приложение автоматически проверяет:

- Обязательные поля (NOT NULL)
- Формат дат (YYYY-MM-DD)
- Формат времени (YYYY-MM-DD HH:MM:SS)
- Формат чисел (для integer, bigint, smallint)
- Максимальная длина строковых полей
- Существование связанных записей (для внешних ключей)

При обнаружении ошибки валидации появится сообщение с описанием проблемы.

## Обработка ошибок

При возникновении ошибок приложение отображает информативные сообщения:

- **Ошибка подключения** - проверьте параметры подключения в `config.ini` и переменную `PGPASSWORD`
- **Ошибка выполнения запроса** - проверьте синтаксис SQL запроса
- **Ошибка валидации** - исправьте данные согласно требованиям
- **Ошибка транзакции** - операция была отменена, данные не изменены

## Структура базы данных

База данных содержит следующие таблицы:

1. **prizivnik** - призывники
2. **comissar** - комиссары
3. **kategoria_godnosti** - категории годности
4. **voennyi_bilet** - военные билеты
5. **voenno_uchetnaya_karta** - военно-учётные карты
6. **med_osvidetelstvovanie** - медицинские освидетельствования
7. **prizivnoe_meropriyatie** - призывные мероприятия
8. **prizivnik_comissar** - связь призывник-комиссар (составной ключ)
9. **prizivnik_meropriyatie** - связь призывник-мероприятие (составной ключ)

Подробное описание схемы базы данных см. в `docs/database_schema.md`.

## Особенности работы с составными ключами

Таблицы `prizivnik_comissar` и `prizivnik_meropriyatie` имеют составные первичные ключи (несколько полей вместе образуют уникальный ключ).

При работе с этими таблицами:
- Удаление записей работает корректно
- Редактирование записей может требовать дополнительных действий
- При добавлении записей необходимо указать все поля, входящие в составной ключ

## Советы по использованию

1. **Регулярно создавайте резервные копии** - используйте функцию "Экспорт данных" перед важными операциями
2. **Проверяйте данные перед сохранением** - приложение покажет ошибки валидации
3. **Используйте транзакции** - приложение автоматически использует транзакции для операций изменения данных
4. **Экспортируйте результаты** - используйте экспорт в CSV для анализа данных в Excel

## Устранение проблем

### Проблема: "База данных не подключена"

**Решение:**
1. Проверьте, запущен ли PostgreSQL
2. Проверьте файл `config.ini` - должны быть указаны правильные параметры
3. Проверьте переменную окружения `PGPASSWORD`

### Проблема: "password authentication failed"

**Решение:**
1. Проверьте правильность пароля в переменной `PGPASSWORD`
2. Убедитесь, что переменная установлена в текущей сессии PowerShell

### Проблема: "Не удалось выполнить запрос"

**Решение:**
1. Проверьте синтаксис SQL запроса
2. Убедитесь, что все используемые таблицы и поля существуют
3. Проверьте права доступа к базе данных

### Проблема: "Не удалось создать файл"

**Решение:**
1. Проверьте права доступа к папке `exports/`
2. Убедитесь, что достаточно места на диске
3. Закройте файл, если он открыт в другой программе
