# Сводка информации о подключении к БД

## Найденные параметры из анализа проекта

### Основные параметры подключения:

| Параметр | Значение | Источник |
|----------|----------|----------|
| **Хост** | `localhost` | `MainWindow.cpp:115`, скрипты запуска |
| **Порт** | `5432` | `MainWindow.cpp:115`, скрипты запуска |
| **База данных** | `voenkomat` | `MainWindow.cpp:115`, `README.md`, скрипты |
| **Пользователь** | `postgres` | `MainWindow.cpp:115`, скрипты запуска |
| **Пароль** | *пустая строка в коде* | `MainWindow.cpp:115` - требуется указать |

### Текущее состояние в коде:

**Файл:** `src/MainWindow.cpp` (строка 115)

```cpp
return m_dbManager->connectToDatabase("localhost", "5432", "voenkomat", "postgres", "");
```

**Проблема:** Пароль захардкожен как пустая строка `""`.

## Что нужно сделать

### 1. Получить пароль от БД

Используйте один из способов из `docs/database_connection.md`:
- Через pgAdmin (Properties → Connection)
- Через консоль psql
- Через SQL запрос

### 2. Создать конфигурационный файл

После получения пароля, будет создан файл `config.ini`:

```ini
[Database]
host=localhost
port=5432
database=voenkomat
username=postgres
password=ВАШ_ПАРОЛЬ_ЗДЕСЬ
```

### 3. Обновить код

Код будет обновлен для использования `ConfigManager` вместо захардкоженных значений.

## Проверка подключения

После получения пароля, можно проверить подключение:

**Через PowerShell:**
```powershell
$env:PGPASSWORD = "ваш_пароль"
psql -h localhost -p 5432 -U postgres -d voenkomat -c "SELECT version();"
```

**Через приложение:**
После создания `config.ini` приложение автоматически подключится при запуске.
