# Инструкция по запуску проекта "Военкомат"

## Что нужно для запуска

1. **Qt Creator 5.5.1** (или выше) с MinGW компилятором
2. **PostgreSQL 17** (установлен и запущен)
3. **База данных `voenkomat`** (создана и восстановлена из бэкапа)
4. **Переменная окружения `PGPASSWORD`** (установлена)

---

## Пошаговая инструкция

### Шаг 1: Проверка PostgreSQL

Убедитесь, что PostgreSQL запущен:

1. Нажмите **Win + R**
2. Введите `services.msc` и нажмите **Enter**
3. Найдите службу **postgresql-x64-17** (или похожую)
4. Убедитесь, что статус: **Запущена**
5. Если не запущена - нажмите **Запустить**

---

### Шаг 2: Проверка базы данных

Убедитесь, что база данных `voenkomat` существует:

#### Вариант A: Через PowerShell

```powershell
# 1. Откройте PowerShell
# 2. Перейдите в папку проекта
cd "C:\Универ\SEM_5\БД\voenkomat_app"

# 3. Установите пароль (замените на ваш!)
$env:PGPASSWORD = "ваш_пароль"

# 4. Проверьте подключение
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h localhost -p 5432 -U postgres -d voenkomat -c "SELECT version();"
```

Если база данных не существует, создайте её и восстановите из бэкапа:

```powershell
# 1. Создайте базу данных
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h localhost -p 5432 -U postgres -d postgres -c "CREATE DATABASE voenkomat;"

# 2. Восстановите из бэкапа
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h localhost -p 5432 -U postgres -d voenkomat -f "sql_zaproses\new_backup.sql"
```

#### Вариант B: Через pgAdmin

1. Откройте **pgAdmin**
2. Разверните **Servers** → **PostgreSQL 17** → **Databases**
3. Если база `voenkomat` не существует:
   - Правой кнопкой на **Databases** → **Create** → **Database**
   - Имя: `voenkomat`
   - Нажмите **Save**
4. Восстановите из бэкапа:
   - Правой кнопкой на `voenkomat` → **Restore**
   - Выберите файл `sql_zaproses\new_backup.sql`
   - Нажмите **Restore**

---

### Шаг 3: Настройка переменной окружения PGPASSWORD

Пароль должен быть установлен в переменной окружения `PGPASSWORD`.

#### Вариант A: Временная установка (для текущей сессии)

Откройте PowerShell и выполните:

```powershell
$env:PGPASSWORD = "ваш_пароль"
```

**Примечание:** Эта переменная будет действовать только в текущем окне PowerShell.

#### Вариант B: Постоянная установка (рекомендуется)

##### Способ 1: Через PowerShell (от администратора)

```powershell
[System.Environment]::SetEnvironmentVariable("PGPASSWORD", "ваш_пароль", "User")
```

После выполнения перезапустите PowerShell.

##### Способ 2: Через графический интерфейс Windows

1. Нажмите **Win + X** → **Система**
2. Нажмите **Дополнительные параметры системы**
3. Нажмите **Переменные среды**
4. В разделе **Переменные пользователя** нажмите **Создать**
5. Введите:
   - **Имя переменной:** `PGPASSWORD`
   - **Значение переменной:** `ваш_пароль`
6. Нажмите **ОК** везде
7. **Перезапустите** все приложения, которые используют эту переменную

##### Способ 3: Через командную строку (CMD)

```cmd
setx PGPASSWORD "ваш_пароль"
```

**Примечание:** После выполнения `setx` нужно перезапустить командную строку/PowerShell.

#### Проверка установки

Выполните в PowerShell:

```powershell
$env:PGPASSWORD
```

Должно вывести ваш пароль.

### Шаг 4: Проверка файла конфигурации

Убедитесь, что файл `config.ini` существует в корне проекта:

```
voenkomat_app/
├── config.ini          ← Этот файл должен существовать
├── config.ini.example  ← Шаблон конфигурации
└── ...
```

Если файл `config.ini` не существует, создайте его на основе `config.ini.example`:

```ini
[Database]
host=localhost
port=5432
database=voenkomat
username=postgres
# Пароль не хранится здесь - используется переменная окружения PGPASSWORD
```

**Примечание:** Пароль НЕ нужно указывать в `config.ini` - он берется из переменной окружения `PGPASSWORD`.

### Шаг 5: Открытие проекта в Qt Creator

1. Откройте **Qt Creator**
2. Выберите **File** → **Open File or Project** (или **Ctrl + O**)
3. Перейдите в папку проекта: `C:\Универ\SEM_5\БД\voenkomat_app`
4. Выберите файл **`voenkomat_app.pro`**
5. Нажмите **Open**

---

### Шаг 6: Настройка сборки

1. В Qt Creator выберите **Projects** (или **Ctrl + 5**)
2. Убедитесь, что выбран **Kit** с Qt 5.5.1 MinGW:
   - **Qt Version:** Qt 5.5.1 MinGW
   - **Compiler:** MinGW (C++11)
3. Выберите **Build Settings**:
   - **Build directory:** оставьте по умолчанию (`build-voenkomat_app-...`)
4. Выберите **Run Settings**:
   - **Run directory:** оставьте по умолчанию

---

### Шаг 7: Сборка проекта

1. Нажмите **Build** → **Build Project** (или **Ctrl + B**)
2. Дождитесь завершения сборки
3. Проверьте, что нет ошибок компиляции

**Примечание:** Если возникают ошибки, проверьте:
- Установлен ли Qt 5.5.1 MinGW
- Правильно ли настроен Kit в Qt Creator
- Все ли файлы исходного кода присутствуют

---

### Шаг 8: Запуск проекта

#### Вариант A: Запуск из Qt Creator

1. Нажмите **Run** → **Run** (или **Ctrl + R**)
2. Приложение должно запуститься
3. При первом запуске приложение автоматически подключится к базе данных

#### Вариант B: Запуск из командной строки

Если вы хотите запустить приложение из командной строки:

1. Откройте PowerShell
2. Установите переменную окружения (если еще не установлена):
   ```powershell
   $env:PGPASSWORD = "ваш_пароль"
   ```
3. Перейдите в папку с исполняемым файлом:
   ```powershell
   cd "C:\Универ\SEM_5\БД\voenkomat_app\debug"  # или \release
   ```
4. Запустите приложение:
   ```powershell
   .\voenkomat_app.exe
   ```

---

### Шаг 9: Проверка работы приложения

После запуска приложения:

1. Должно открыться главное окно приложения "Военкомат"
2. Приложение автоматически подключится к базе данных
3. Если подключение успешно, вы увидите главное меню с кнопками:
   - **Запросы** - выполнение SQL-запросов
   - **Таблицы** - просмотр и управление таблицами
   - **Добавить таблицу** - создание новой таблицы
   - **Экспорт данных** - создание резервной копии
   - **Восстановить данные** - восстановление из бэкапа
   - **Восстановить таблицу** - восстановление отдельной таблицы
   - **Выход** - закрытие приложения

## Устранение проблем

### Ошибка: "password authentication failed"

**Причина:** Неправильный пароль или переменная `PGPASSWORD` не установлена.

**Решение:**
1. Проверьте переменную: `$env:PGPASSWORD`
2. Установите правильный пароль: `$env:PGPASSWORD = "ваш_пароль"`
3. Перезапустите приложение

### Ошибка: "could not connect to server"

**Причина:** PostgreSQL не запущен.

**Решение:**
1. Откройте **services.msc**
2. Найдите службу **postgresql-x64-17**
3. Убедитесь, что она **Запущена**
4. Если не запущена - нажмите **Запустить**

### Ошибка: "database does not exist"

**Причина:** База данных `voenkomat` не существует.

**Решение:**
1. Создайте базу данных (см. Шаг 2)
2. Восстановите из бэкапа (см. Шаг 2)

### Ошибка: "QPSQL driver not loaded"

**Причина:** Драйвер PostgreSQL не установлен или не найден.

**Решение:**
1. Убедитесь, что PostgreSQL установлен
2. Проверьте, что в Qt Creator выбран правильный Kit с Qt 5.5.1
3. Пересоберите проект

### Ошибка компиляции: "Cannot find -lqsqlpsql"

**Причина:** Драйвер QPSQL не скомпилирован для вашей версии Qt.

**Решение:**
1. Убедитесь, что PostgreSQL установлен
2. Проверьте, что драйвер QPSQL доступен в Qt
3. При необходимости скомпилируйте драйвер QPSQL вручную
