# Пошаговый гайд: Использование 32-битной libpq.dll для PostgreSQL 17

## Проблема
Ваше приложение скомпилировано как 32-битное (Qt 5.5.1 MinGW 32-bit), но PostgreSQL 17 предоставляет только 64-битную версию `libpq.dll`. 32-битное приложение не может загрузить 64-битную DLL.

## Решение
Использовать 32-битную версию `libpq.dll` от PostgreSQL 12 или 13. Протокол PostgreSQL обратно совместим, поэтому 32-битный клиент от старой версии сможет подключиться к PostgreSQL 17 серверу.

---

## Шаг 1: Скачать PostgreSQL 12 или 13 (32-bit)

1. Откройте браузер и перейдите на официальный сайт PostgreSQL:
   ```
   https://www.postgresql.org/download/windows/
   ```

2. Найдите раздел "PostgreSQL 12" или "PostgreSQL 13"

3. Нажмите на ссылку "Download the installer"

4. Выберите **32-bit** версию установщика (не 64-bit!)
   - Обычно это файл вида: `postgresql-12.x-x-windows-x86.exe` или `postgresql-13.x-x-windows-x86.exe`
   - Размер примерно 100-150 МБ

---

## Шаг 2: Установить PostgreSQL 12/13 (только клиентские библиотеки)

1. Запустите скачанный установщик

2. На экране "Select Components" выберите:
   - ✅ **Command Line Tools** (обязательно)
   - ✅ **pgAdmin 4** (опционально, не обязательно)
   - ❌ **PostgreSQL Server** (НЕ выбирайте - сервер не нужен!)
   - ❌ **Stack Builder** (НЕ выбирайте)

3. На экране "Data Directory" можете оставить значения по умолчанию (сервер не будет установлен, так что это не важно)

4. На экране "Password" можете ввести любой пароль (сервер не будет использоваться)

5. На экране "Port" можете оставить 5432 (не важно, сервер не будет запущен)

6. Завершите установку

---

## Шаг 3: Найти и скопировать необходимые файлы

1. Откройте Проводник Windows

2. Перейдите в папку установки PostgreSQL 12/13:
   ```
   C:\Program Files (x86)\PostgreSQL\12\bin\
   ```
   или
   ```
   C:\Program Files (x86)\PostgreSQL\13\bin\
   ```
   
   **Примечание:** Если вы не видите папку `Program Files (x86)`, проверьте:
   - `C:\Program Files\PostgreSQL\12\bin\` (если установилась в обычную папку)
   - Или используйте поиск Windows: найдите файл `libpq.dll` и посмотрите его расположение

3. В этой папке найдите следующие файлы:
   - `libpq.dll` (обязательный)
   - `libiconv-2.dll` (опциональный, но рекомендуется)
   - `libintl-8.dll` (опциональный, но рекомендуется)

4. Скопируйте эти файлы (Ctrl+C)

5. Перейдите в папку вашего проекта:
   ```
   C:\QT_projects\voenkomat_app\debug\
   ```

6. Вставьте скопированные файлы (Ctrl+V)

7. Убедитесь, что файлы скопированы:
   - Должен быть `libpq.dll` (размер примерно 300-400 КБ для 32-bit версии)
   - Должны быть `libiconv-2.dll` и `libintl-8.dll` (если они были в исходной папке)

---

## Шаг 4: Удалить старую 64-битную версию libpq.dll (если есть)

1. В папке `C:\QT_projects\voenkomat_app\debug\` проверьте, есть ли там старый `libpq.dll`

2. Если есть, удалите его (или переименуйте в `libpq.dll.old` для резервной копии)

3. Убедитесь, что теперь в папке `debug` находится 32-битная версия `libpq.dll` от PostgreSQL 12/13

---

## Шаг 5: Проверить результат

1. Запустите ваше приложение в Qt Creator

2. Проверьте вывод консоли - должно появиться:
   ```
   libpq.dll успешно загружен
   ```

3. Если видите ошибку "не является приложением Win32" - значит скопировали не ту версию (64-bit вместо 32-bit)

4. Если все правильно, приложение должно подключиться к PostgreSQL 17 серверу

---

## Проверка архитектуры DLL (опционально)

Если хотите убедиться, что DLL действительно 32-битная:

1. Откройте PowerShell

2. Выполните команду:
   ```powershell
   [System.Reflection.Assembly]::LoadFile("C:\QT_projects\voenkomat_app\debug\libpq.dll")
   ```
   
   Если получите ошибку "BadImageFormatException" - это 64-битная DLL (не подходит)
   
   Если ошибки нет - это 32-битная DLL (подходит)

   **Примечание:** Этот способ может не сработать для DLL, которые не являются .NET сборками. В этом случае просто проверьте размер файла - 32-битная версия обычно меньше 64-битной.

---

## Альтернативный способ: Скачать только клиентские библиотеки

Если не хотите устанавливать весь PostgreSQL 12/13:

1. Найдите в интернете "PostgreSQL 12 windows x86 binaries" или "PostgreSQL 12 32-bit client libraries"

2. Скачайте архив с бинарными файлами

3. Извлеките из архива только файлы из папки `bin`:
   - `libpq.dll`
   - `libiconv-2.dll`
   - `libintl-8.dll`

4. Скопируйте их в `C:\QT_projects\voenkomat_app\debug\`

---

## Важные замечания

1. **Протокол совместим:** 32-битный клиент от PostgreSQL 12/13 может подключиться к PostgreSQL 17 серверу без проблем

2. **Только libpq.dll:** Вам нужна только библиотека `libpq.dll` от старой версии. Сервер PostgreSQL 17 может продолжать работать как обычно

3. **Размер файла:** 32-битная версия `libpq.dll` обычно имеет размер около 300-400 КБ, а 64-битная - около 500-600 КБ

4. **Путь установки:** PostgreSQL 12/13 (32-bit) обычно устанавливается в `Program Files (x86)`, а PostgreSQL 17 (64-bit) - в `Program Files`

---

## Если что-то пошло не так

### Ошибка: "libpq.dll не может загрузиться: не является приложением Win32"
- **Причина:** Скопировали 64-битную версию вместо 32-битной
- **Решение:** Убедитесь, что скачали и установили именно 32-bit версию PostgreSQL 12/13

### Ошибка: "libpq.dll не найден"
- **Причина:** Файл не скопирован в правильную папку
- **Решение:** Проверьте, что `libpq.dll` находится в `C:\QT_projects\voenkomat_app\debug\`

### Ошибка подключения к серверу
- **Причина:** Проблема с сетью или настройками подключения
- **Решение:** Проверьте, что PostgreSQL 17 сервер запущен и доступен на localhost:5432

---

## Готово!

После выполнения всех шагов ваше 32-битное приложение должно успешно подключиться к PostgreSQL 17 серверу, используя 32-битную версию `libpq.dll` от PostgreSQL 12/13.
