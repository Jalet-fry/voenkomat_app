# Простая инструкция: Установка 32-bit libpq.dll

## Что нужно сделать

Всего 3 простых шага:

---

## ШАГ 1: Скачать PostgreSQL 12 (32-bit)

### Вариант A: Прямая ссылка (рекомендуется)

1. Откройте эту ссылку в браузере:
   ```
   https://www.enterprisedb.com/download-postgresql-binaries
   ```

2. Или найдите на официальном сайте:
   - Перейдите: https://www.postgresql.org/download/windows/
   - Найдите "PostgreSQL 12" или "PostgreSQL 13"
   - Скачайте версию с пометкой **"x86"** или **"32-bit"**

3. Файл будет называться примерно так:
   - `postgresql-12.18-windows-x86.exe` (32-bit)
   - НЕ `postgresql-12.18-windows-x64.exe` (это 64-bit, не подходит!)

### Вариант B: Альтернативный источник

Если официальный сайт не работает, можно скачать с:
- https://get.enterprisedb.com/postgresql/postgresql-12.18-1-windows-x86.exe

---

## ШАГ 2: Установить (только клиентские библиотеки)

1. **Запустите установщик** (файл .exe, который скачали)

2. На экране **"Select Components"** (Выбор компонентов):
   
   ✅ **ВЫБЕРИТЕ:**
   - Command Line Tools
   
   ❌ **НЕ ВЫБИРАЙТЕ:**
   - PostgreSQL Server (сервер не нужен!)
   - Stack Builder
   - pgAdmin (можно, но не обязательно)

3. Нажмите **"Next"** и завершите установку
   - Пароль и порт можно ввести любые (сервер не будет использоваться)

---

## ШАГ 3: Скопировать файлы

### Способ 1: Автоматически (скрипт)

Запустите скрипт `install_32bit_libpq.ps1` (я создам его ниже)

### Способ 2: Вручную

1. Откройте Проводник Windows

2. Перейдите в папку:
   ```
   C:\Program Files (x86)\PostgreSQL\12\bin\
   ```
   
   **Если папки нет**, проверьте:
   - `C:\Program Files\PostgreSQL\12\bin\`
   - Или используйте поиск Windows: найдите файл `libpq.dll`

3. Скопируйте эти файлы (выделите и Ctrl+C):
   - `libpq.dll`
   - `libiconv-2.dll` (если есть)
   - `libintl-8.dll` (если есть)

4. Перейдите в папку вашего проекта:
   ```
   C:\QT_projects\voenkomat_app\debug\
   ```

5. Вставьте файлы (Ctrl+V)

6. **Готово!** ✅

---

## Проверка

После копирования файлов:

1. Запустите ваше приложение
2. В логах должно появиться: `libpq.dll успешно загружен`
3. Приложение должно подключиться к PostgreSQL 17

---

## Если что-то пошло не так

### Ошибка: "Папка Program Files (x86) не найдена"
- PostgreSQL 12 мог установиться в `C:\Program Files\PostgreSQL\12\bin\`
- Используйте поиск Windows: найдите `libpq.dll` и посмотрите, где он находится

### Ошибка: "Не могу найти файл libpq.dll"
- Убедитесь, что установили "Command Line Tools" при установке PostgreSQL 12
- Переустановите PostgreSQL 12, выбрав "Command Line Tools"

### Ошибка: "Все равно не работает"
- Убедитесь, что скопировали файлы именно в папку `debug` (где находится `voenkomat_app.exe`)
- Проверьте, что файл `libpq.dll` имеет размер примерно 300-400 КБ (32-bit версия меньше 64-bit)
