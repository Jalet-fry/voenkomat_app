# Как получить 32-битную версию libpq.dll для PostgreSQL 17

## Вариант 1: Скачать только клиентские библиотеки PostgreSQL 12/13 (32-bit)

1. Скачайте PostgreSQL 12 или 13 (32-bit версию) с официального сайта:
   - https://www.postgresql.org/download/windows/
   - Выберите версию 12 или 13
   - Выберите 32-bit установщик

2. При установке выберите только "Command Line Tools" или "Client only"
   - НЕ устанавливайте сервер
   - Это установит только клиентские библиотеки

3. Скопируйте файлы из `C:\Program Files (x86)\PostgreSQL\12\bin\` (или `13\bin\`):
   - `libpq.dll`
   - `libiconv-2.dll` (если есть)
   - `libintl-8.dll` (если есть)

4. Вставьте их в `C:\QT_projects\voenkomat_app\debug\`

## Вариант 2: Использовать готовые бинарники

Можно скачать только клиентские библиотеки без установки всего PostgreSQL.

## Важно

32-битная версия libpq.dll от PostgreSQL 12/13 **должна работать** с PostgreSQL 17 сервером, так как протокол обратно совместим.
